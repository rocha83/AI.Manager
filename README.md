## English

AI.Manager is the .NET 10 platform for managing, automating and training AI models. It consolidates domain, application, infrastructure and training engine into a reusable core (`Rochas.AI.Manager.Core`) plus API and Web hosts.

### Installation

```bash
dotnet add package Rochas.AI.Manager.Core
```

### Quick start

```bash
dotnet run --project src/Rochas.AI.Manager.Api
```
